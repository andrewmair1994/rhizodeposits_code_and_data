This document details how to setup fenics on a Windows machine so that the codes in this repository can be run.

#########################################################################
1. Installing docker
#########################################################################

Install Docker on your windows machine by following the guidance on https://docs.docker.com/docker-for-windows/install/.
   The video https://www.youtube.com/watch?v=_9AWYlt86B8&t=304s is also helpful.


#########################################################################
2. Building docker image and container
#########################################################################

Open command prompt

(a). Open the windows command prompt and navigate to the directory where you have saved the code, data, and supporting documents associated with the DOI this directory will hereafter be referred to as "rhizodeposits_code_and_data".

(b). Navigate into the folder named "fenics-ghcr-repo-image" and build your FEniCS image by running the following command:

	docker build -t fenics-2019-ghcr .
     
     Here the image is named "fenics-2019-ghcr" but you could choose any other name you like.

#########################################################################
3. Running naming and mounting directory to the docker container 
#########################################################################

Name the created container say "rhizodeposits-container" and share files from the current directory path for example C:\Users\me\Documents\rhizodeposits_code_and_data into the container by running the following command

	docker run -it --name rhizodeposits-container -v C:\Users\me\Documents\rhizodeposits_code_and_data:/home/fenics/shared fenics-2019-ghcr bash

This will start the container and give it the name "rhizodeposits-container". The output should then look something like this

	root@70a3a723b077:/#

To exit the container run
	
	exit

#########################################################################
4. Starting, running codes and exiting the container
#########################################################################

Whenever you want to run codes you have downloaded from the DOI you should use the following procedure:  
(a). Open Command prompt and navigate to DOI_folder.
(b). To start the container rhizodeposits-container run the command:


	docker start -ai rhizodeposits-container

(c). Navigate within the container as follows to access the working directory you had previously mounted.

 	cd home/fenics/shared

(d). By running the command:
	
		ls

     you should see all the contents of the DOI rhizodeposits_code_and_data.

(e). To run one of the .py scripts, say "script_xyz.py", within this container, run the command:
	
		python3 script_xyz.py

	The .py codes of this project were all written using the text editor Spyder, though other text editors
        such as VIM and Atom will also work.
